# For Manna ♡

A romantic, mobile-first static website made as a personal letter.

## Run locally
1. Open this folder in VS Code.
2. Install the **Live Server** extension (or use any static web server).
3. Right-click `index.html` → **Open with Live Server**.

You can also simply open `index.html` in a browser.

## Add / change photos
Your included photos are in `assets/`. The page currently references:
- `assets/together-1.jpeg`
- `assets/together-2.jpeg`
- `assets/manna-cafe.jpeg`
- `assets/manna-roses.jpeg`

To replace a photo, use the same filename or change the matching `src` in `index.html`.

## Publish it free with GitHub Pages
1. Create a GitHub repository, e.g. `for-manna`.
2. Upload `index.html`, `style.css`, `script.js`, and the `assets` folder to the repository root.
3. On GitHub, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`, then click **Save**.
6. Wait a minute or two. GitHub will show a public URL like `https://YOUR-USERNAME.github.io/for-manna/`.
7. Open that URL on your phone before sending it to Manna.

Important: the photos are included in the repository, so anyone with the public link can view them. Only publish photos you are both comfortable sharing. This site does not collect responses or track visitors.
